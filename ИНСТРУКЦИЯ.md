# Десять строк

Сайт пишет десять вариантов текста по одной задаче: заголовок, слоган, объявление, тему письма, хук, УТП или призыв. Регистрации нет. Ключ к модели остаётся на сервере.

Нужен Node.js 22. Зависимости уже стоят в `node_modules`. Если папки нет, в корне проекта выполните:

```
npm install
```

## Ключ

В корне проекта должен быть файл `.env`:

```
XAI_API_KEY=ваш_ключ
```

Ключ берётся в кабинете AITunnel. В браузер он не попадает. После правки `.env` сервер нужно остановить и запустить снова: файл читается только при старте.

## Запуск

Откройте терминал в папке проекта и выполните:

```
node server.js
```

В консоли появится строка `listening on 4173`. Сайт открывается по адресу:

```
http://127.0.0.1:4173
```

Если задана переменная `PORT` или `VIBEFORGE_SESSION_PORT`, сервер занимает её, а не 4173. Остановить сервер: `Ctrl+C` в том же терминале.

Во вкладке «Результат» тот же запуск делает команда `node server.js`.

## Go Live в VS Code

Кнопка Go Live показывает только страницу. Генерацию она сама не выполняет: запросы `/api` нужно передать серверу Node.

1. В терминале, в папке проекта, выполните `node server.js` и оставьте это окно открытым.
2. Остановите Go Live, если он уже был включён, и нажмите Go Live снова. Настройка прокси читается при старте.
3. Откройте страницу, которую показал Go Live, и нажмите «Сгенерировать».

Порт сервера должен быть `4173`. Если в консоли другой порт, в `.vscode/settings.json` поправьте `proxyUri`.

## Как пользоваться

1. Выберите тип текста, тон и длину.
2. Опишите задачу. Это единственное обязательное поле.
3. Бренд, аудиторию и оффер заполняйте только если они нужны. Пустые поля в запрос не уходят, и модель их не выдумывает.
4. Нажмите «Сгенерировать». Появятся десять вариантов.
5. «Скопировать» копирует одну строку. «Сгенерировать заново» заменяет весь набор.
6. Обновление страницы стирает результат. История нигде не сохраняется.

Язык вариантов совпадает с языком задачи.

## Деплой на Vercel

Страницы лежат в `public`, запрос генерации обрабатывает `api/generate.js`. Папка с кодом называется `src`, не `lib`: Vercel и git часто пропускают `lib` как папку сборки, из-за этого деплой падает с `Could not resolve './lib/copy.js'`.

В настройках проекта Vercel:

- Framework Preset: Other.
- Build Command оставьте пустым. Команда, которая собирает только `server.js`, снова не увидит модули.
- В Environment Variables добавьте `XAI_API_KEY`. Файл `.env` на Vercel не попадает.

После этого задеплойте проект ещё раз, вместе с папками `src`, `api` и `public`.

## Проверка

```
node --test
```

Ожидается 8 прошедших тестов.

## Если генерация не удалась

- «Сервер не настроен: отсутствует XAI_API_KEY.» — нет `.env` или в нём пустой ключ. Добавьте ключ и перезапустите сервер.
- «Не удалось получить тексты. Попробуйте ещё раз.» — запрос до модели не дошёл или ответ не разобрался. Проверьте ключ и баланс AITunnel, затем повторите.
- «Заполните задачу.» — в поле задачи только пробелы. Напишите, что нужно сказать.
